## Scope

This alpha contains the accepted local-safe `0.5.x` Formula / Research Export scope, together with the previously completed `0.1.x`–`0.4.x` local-safe workflow.

Notable `0.5.x` additions:

- local formula region model and queue plumbing;
- formula-region photo overlay, drag-to-draft selection and saved-region editing;
- manual LaTeX durable queue and READY formula result export;
- deterministic `references.bib` and `references.ris` export artifacts;
- Markdown / Notion-ready export coverage for accepted local data.

Deferred and not included:

- live Mathpix provider;
- PaddleOCR / pix2tex bundling;
- real ASR / online AI summary provider runtime;
- Notion live OAuth/upload;
- cloud upload, login, sync, ads, payment, subscriptions or recurring-cost backend work;
- Google Play production signing or production AAB release.

## User Notes

Download the APK from the GitHub `Releases` page and sideload it as `SeminarArc Internal`. It is an alpha/dogfood build, not a Google Play production build.

The recommended next step is personal-device dogfood: run one short test seminar through capture -> reconstruction -> reference/brief -> formula/export, then use the app in a low-risk real seminar if the smoke test is stable.
