# Privacy

SeminarArc is designed to store seminar materials locally on the device by default.

## Local-first behavior

- Seminar metadata is stored in the local app database
- Imported PDFs are copied into app-private storage
- Later batches will store recordings, generated clips, and slide photos in app-private storage

## User responsibility

Users must obtain permission before recording seminars, talks, or discussions.

## Current scope

This repository does not include:

- cloud sync
- account login
- remote upload
- AI transcription or summaries
