# 0.4.x Transcription / Summary Provider Contract Task

## Goal

Add local-safe provider contracts for future transcription and summary generation without introducing live provider credentials, cloud upload, Notion OAuth, backend deployment, or user-data exfiltration.

## Inputs

- `AGENTS.md`
- `prompts/AGENT_RULES.md`
- `prompts/tasks/0.4.x_transcript_schema_domain_task.md`
- `prompts/tasks/0.4.x_transcript_schema_domain_result.md`
- `docs/plans/0.4.x-transcription-summary-notion-plan.md`

## Required Work

- Add `TranscriptionProvider` contract with provider id/version, request model, timestamp granularity, segment draft output, success/failure result, language hint, and retryability.
- Add `SummaryProvider` contract with user-selected transcript windows, references, key-slide captions, user notes, input fingerprint, draft content, provenance, and retryability.
- Add JVM contract tests using fake providers only.
- Keep all provider implementations local and deterministic in tests; do not add live network calls or credentials.

## Constraints

- Do not read, upload, or transmit real seminar recordings, transcript text, photos, OCR corpus, timeline, exports, logs, or private app data.
- Do not add OpenAI, Alibaba, Notion, or other live provider credentials.
- Do not bind new providers into production Hilt yet.
- Do not run connected Android tests while Windows ADB sees protected physical device serial `8cc54656`.

## Output

- Write `prompts/tasks/0.4.x_transcription_provider_contract_result.md`.
- End with `IMPLEMENTATION_PASS` or `PARTIAL_DEVICE_GATE_BLOCKED`.
