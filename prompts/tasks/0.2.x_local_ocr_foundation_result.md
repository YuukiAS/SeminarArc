# 0.2.x Local OCR Foundation Result

## Summary

Implemented the first production local OCR foundation for `0.2.x`.

## Delivered

- Added bundled ML Kit Text Recognition dependencies for Latin and Chinese recognizers.
- Added `TextOcrProvider`, `TextOcrLanguageMode`, `TextOcrRecognition`, and `TextOcrResult` domain models.
- Added `MlKitTextOcrProvider`, which runs Latin, Chinese, or mixed recognizers locally and maps recognized blocks/lines into app-owned lightweight JSON.
- Added `RunTextOcrForAssetUseCase`, which accepts original/enhanced photo assets, resolves app-owned local files, saves OCR output to `ocr_results`, and records durable `TEXT_OCR` job state.
- Added Hilt binding for the OCR provider.
- Added JVM tests for OCR success persistence, provider metadata, job success linkage, and retryable failure state.
