# 0.2.x OCR Result And Tag Model Result

## 完成内容

- 新增 `OcrResult` domain model 和 `OcrResultEntity`。
- 新增 `SeminarSystemTag` / `AssetTag` domain model。
- 新增 `TagEntity` 与 `AssetTagEntity`。
- `ReconstructionRepository.saveOcrResult` 支持同一 asset 的 OCR result replacement 和 edited state。
- `ReconstructionRepository.setSystemTag` 支持 key slide 等系统标签开关。

## 关键语义

- OCR result 是 app-owned model，不保存 provider 私有响应作为唯一事实。
- `assetId` 在 `ocr_results` 中唯一，第一版保持每个 asset 一个最新 OCR result。
- 系统标签包括 `KEY_SLIDE`、`BACKGROUND`、`METHOD`、`RESULT`、`REFERENCE`、`FORMULA`、`FOLLOW_UP`。

- `ReconstructionRepositoryImplTest.setSystemTag_togglesAssetTag`
