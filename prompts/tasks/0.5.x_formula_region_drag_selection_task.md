# 0.5.x Formula Region Drag Selection Task

## Goal

Add controlled drag-to-draft formula region selection on Reconstruction photo previews so users can create normalized crop drafts visually before explicitly saving them.

## Scope

- Keep saved formula region overlays visible on decoded photo previews.
- Add pointer-based drag selection that updates the existing `X/Y/Width/Height` draft fields.
- Draw the current draft region separately from saved regions.
- Require the existing `Save formula region` action before any Room persistence.
- Add Compose test coverage for drag-driven draft update and explicit save.

## Out of Scope

- Saved region resize handles or persisted edit-in-place.
- Live formula OCR provider execution.
- Automatic OCR enqueueing from drag.
- Cloud upload, credential storage, backend, Zotero sync or Notion live upload.
- Connected device execution against protected physical hardware.

## Validation

- JVM tests and androidTest Kotlin compile.
- Lint and internal APK build.
- Signature/hash/secret/cache checks before commit.
