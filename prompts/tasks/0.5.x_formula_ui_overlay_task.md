# 0.5.x Formula UI Overlay Task

## Goal

Show saved formula regions directly on Reconstruction photo previews so users can visually verify formula crops before provider work or manual LaTeX editing.

## Scope

- Draw saved `FormulaRegion` normalized crop rectangles on the photo preview.
- Use Material theme colors and keep the existing photo card layout.
- Add an accessibility description that includes the formula region count.
- Keep crop creation on the explicit existing save form for this batch.

## Out of Scope

- Gesture-based region creation or resizing.
- Live formula OCR provider execution.
- Cloud upload, credential storage, backend, Zotero sync or Notion live upload.
- Connected device execution against protected physical hardware.

## Validation

- JVM tests and androidTest Kotlin compile.
- Lint and internal APK build.
- Signature/hash/secret/cache checks before commit.
