# 0.4.x Markdown/ZIP Transcript Summary Export Result

## Status

Implemented.

## Changes

- Extended export document models with transcript review, transcript segments, transcript timeline windows, and generated summary draft DTOs.
- `SeminarExportRepositoryImpl` now gathers local transcripts, transcript segments, summary drafts, and ready-transcript timeline windows when building an export package.
- `SeminarExportAssembler` maps transcript and summary domain data into deterministic export DTOs.
- `SeminarMarkdownRenderer` now emits:
  - `Transcript Review` with provider/state/source/language metadata and timestamped segments,
  - per-transcript `Timeline windows` for ready transcripts,
  - `Generated Summary Drafts` with an explicit editable-draft warning and provenance.
- ZIP compatibility is preserved because `SeminarZipWriter` still writes the enriched Markdown to `<seminar-slug>/seminar.md` and copies readable media assets.
- Added JVM coverage for transcript/summary export assembly and Markdown rendering.

## Privacy / Scope Boundary

- This task exports existing local Room/domain data only.
- No transcript text, photos, recordings, OCR corpus, notes, summary drafts, app-private paths, credentials, or provider inputs are uploaded.
- Generated summary drafts are labeled as editable generated drafts and do not replace the user-authored `SeminarBrief`.
- No live ASR provider, live LLM summary provider, Notion OAuth/upload, backend, private credential, or recurring-cost service was added.
