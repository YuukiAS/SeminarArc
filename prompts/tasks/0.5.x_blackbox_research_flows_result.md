## Fixed Bugs

Production fixes:

- `ActiveSessionScreen`: CameraX photo capture is now bounded by a 15s timeout and reports a normal capture failure instead of leaving the UI stuck indefinitely on Emulator camera stalls.
- `ReconstructionWorkspaceScreen`: `Find references` is now reachable even without OCR/key-slide evidence, enabling the task-required manual DOI/title reference workflow.

Harness fixes:

- Hardened app launch with bounded retries, content readiness checks, and explicit launcher flags.
- Added scoped, bounded logcat capture to avoid long global crash-buffer reads during Emulator load.
- Confirmed system permission denial actually dismisses the dialog before continuing.
- Added robust clickable-ancestor tapping and bidirectional scrolling for long screens.
- Reopened synthetic seminars from the library before persistence checks instead of assuming the current navigation stack.
- Added Android DocumentsUI save retry, picker-dismissal verification, and longer bounded picker wait.
- Added export file and ZIP-entry validation helpers.
- Stabilized B02 text input, B03 photo-only end flow, B05 brief editing, and B08 cleanup/delete navigation.
