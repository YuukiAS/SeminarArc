## 官方资料核对

- OpenAI Whisper repository license is MIT, suitable as an open-source reference path if bundled notices are preserved.
- `whisper.cpp` documents CPU/offline support and Android example/support, making Android feasibility plausible but still requiring device/emulator performance measurements.
- OpenAI hosted Audio transcription supports uploaded audio file transcription and timestamp granularities for supported response/model combinations, but requires cloud upload and private API credential.
- Alibaba Cloud Tingwu speech transcription supports audio/video transcription, languages including Chinese/English/Cantonese/Japanese and speaker separation options, but requires Alibaba Cloud service/account/credential and cloud processing.
- Android platform offline preference via `RecognizerIntent.EXTRA_PREFER_OFFLINE` is implementation-dependent, so it is not a reliable first durable seminar transcript backend.
- Google ML Kit GenAI `SpeechRecognizer` documents on-device speech recognition and model availability/download flow, but its API maturity/runtime behavior requires a separate spike before product commitment.
- Notion API requires secure authorization; OAuth token exchange uses client credentials, and file upload is a dedicated API lifecycle. Public multi-user Notion integration therefore needs backend/secret handling.
- Notion API rate limits average about 3 requests/second per connection and require 429/Retry-After handling.
