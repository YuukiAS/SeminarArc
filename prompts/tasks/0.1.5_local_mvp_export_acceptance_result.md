# 0.1.5 Local MVP Export Acceptance Result

## 完成内容

- 新增 UI-independent export model：`SeminarExportDocument`、`ExportTimelineItem`、`ExportMediaAsset`、`ExportOptions` 和 `SeminarExportPackage`。
- 新增 `SeminarExportAssembler`，将 seminar metadata、abstract、recording summary、timeline events、photos、clip state 和 fallback 文本映射为稳定导出文档。
- 新增 `SeminarMarkdownRenderer`，生成 deterministic Markdown，保留 Unicode、中文、Markdown 特殊字符和 LaTeX-like 文本，并使用 relative media links。
- 新增 `SeminarZipWriter`，按 `<seminar-slug>/seminar.md` 与 `media/abstract|photos|clips/` 写入 ZIP；缺失媒体会跳过并记录，不阻断 Markdown 或其他可读媒体。
- 新增 `SeminarExportRepository` / `SeminarExportRepositoryImpl`，隔离 Android `ContentResolver`、`FileProvider`、app-private media resolution 和 cache-backed share URI。
- 在 Seminar Detail 接入 Markdown/ZIP 保存和分享入口，使用 `ACTION_CREATE_DOCUMENT` 与 Android share sheet；导出过程提供 progress/success/failure 文本状态。
- 更新 README、architecture、privacy 和 changelog，明确 `0.1.5-dev` headless 实现范围、外部导出副本语义和真机 E2E 验收缺口。

## 验证

- `./gradlew testDebugUnitTest assembleDebug`：通过。
- 新增 JVM 测试：
  - `SeminarExportAssemblerTest` 覆盖 seminar/recording/timeline/photo/ready clip/failed clip/missing media 的 export document 映射。
  - `SeminarMarkdownRendererTest` 覆盖 deterministic Markdown、中文、特殊字符、relative links 和 skipped media。
  - `SeminarZipWriterTest` 覆盖 ZIP entry 布局和 missing media skip。

## 未执行的外部验收

- 本轮没有执行真机完整 E2E：创建 seminar、录音、拍照、timeline、clip、重启持久化、离线导出和删除清理。
- 原因：当前线程遵守“先不要求真机验收”和“不允许断开真机或者删除移动任何真机内容”的边界；没有进行设备解锁、安装、录音、拍照、裁剪、导出或删除动作。
- 因此 0.1.5 的代码和 headless gate 已完成，但最终本地 MVP 仍需后续非破坏性真机验收。

## Scope 审计

- 未加入 OCR、transcription、AI summary、Notion、cloud sync、login、ads、subscriptions、payments 或 analytics。
- 未提交导出 ZIP、录音、照片、APK、私人媒体、设备 PIN、密码或本地 secret。
- `AGENTS.md` 只记录 EchoSelect harness 路径和 secret-free 流程；PIN 仍保留在仓库外的本地 secret 文件中。
