# 0.4.x Manual Transcript Import Task

## Objective

Add a local manual transcript import loop so Transcript Review remains useful before a live ASR provider is configured.

## Scope

- Let Transcript Review accept pasted local transcript text.
- Create a `TranscriptSourceType.MANUAL` transcript with a local manual provider id.
- Convert each nonblank line into one coarse editable segment.
- Save the transcript as ready so existing segment editing, summary draft input, Markdown/ZIP export, and Notion-ready export contract can consume it.

## Out of Scope

- No live ASR provider.
- No file picker import.
- No timestamp parser.
- No speaker label editor.
- No cloud upload, Notion OAuth/upload, backend, token storage, or private credential.
- No connected Android test or APK installation while Windows ADB can see protected physical device serial `8cc54656`.

## Verification

- Run headless Gradle verification with D-drive local homes:
  - `.\gradlew.bat --no-daemon testDebugUnitTest compileDebugAndroidTestKotlin`
  - `.\gradlew.bat --no-daemon lintDebug assembleInternal`
- Verify the internal APK with `apksigner`.
- Refresh ignored local release staging APK and SHA-256 file.
