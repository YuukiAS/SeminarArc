# 0.1.4 Clip Playback Resilience Task

## 目标

按 `docs/plans/0.1.4-clip-playback-resilience-plan.md` 实现 marked audio clip 生成、持久状态、失败 fallback 与 retry。

## 范围

- Clip interval 计算：默认 pre-roll `60_000ms`、post-roll `90_000ms`，start clamp 到 `0`，end clamp 到完成录音 duration。
- MARK timeline event 创建后，为有 `recordingId` 的 mark 创建 `PENDING` clip。
- WorkManager worker 按 clip ID 重读 Room/source recording，不把 raw path 当作唯一事实来源。
- 真实输出 app-private `files/seminars/<seminarId>/clips/clip-<id>.m4a`。
- `READY` 才允许播放 clip；`PENDING`、`PROCESSING`、`FAILED` 显示状态并提供完整录音 `Play from here` fallback。
- `FAILED` 支持 retry。
- 删除 mark/clip 时清理 app-owned clip 文件，不删除 source recording。

## 禁止事项

- 不实现 transcription、audio enhancement、speaker diarization、cloud processing、auto-merge overlapping clips、paid/export-specific clip transformations。
- 不伪造 clip 成功；只有真实可读 clip artifact 生成后才能进入 `READY`。
- 不断开、重启、重置真机；不删除或移动真机用户内容。
