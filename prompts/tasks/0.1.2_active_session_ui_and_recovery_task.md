# 0.1.2 Active Session UI、Recovery 与 End Seminar

## 目标

完成 `0.1.2` 当前阶段的现场录音闭环：

```text
durable session truth -> live recorder truth -> recovery -> Active Session UI -> End Seminar
```

## 范围

- 修复 process-start recovery 竞态。
- 区分当前进程 live recorder 与 Room 中遗留 `RECORDING` row。
- 增加 service/coordinator 异常 teardown 语义。
- 新增正式 Active Session route。
- Detail start/resume 成功后进入 Active Session。
- Active Session 展示 seminar identity、recording/recovery/error/permission state、elapsed timer 和 End Seminar。
- End Seminar 通过 use case/repository 层完成 recorder stop/finalize 与 seminar `ACTIVE -> COMPLETED`。
- 补齐 JVM unit tests。
- 更新 README、CHANGELOG、架构/隐私文档。

## 禁止事项

- 不实现 Media3 full recording playback。
- 不实现 CameraX、Capture Slide、timeline event、Mark Moment、Add Question、Quick Note、clip generation。
- 不实现 OCR、transcription、AI、Notion/cloud。
- 不实现 pause/resume recorder。
- 不画假 waveform，不写假 timeline event。

## 验证

至少运行：

```bash
./gradlew --offline testDebugUnitTest
./gradlew --offline assembleDebug
git diff --check
```

如离线缓存允许，可运行 `./gradlew --offline lintDebug`；否则记录具体失败原因。
