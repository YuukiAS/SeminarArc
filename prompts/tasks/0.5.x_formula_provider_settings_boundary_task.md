# 0.5.x Formula Provider Settings Boundary Task

## Goal

Expose UI-facing formula provider readiness and capability status without enabling live Mathpix, cloud OCR, credentials, backend calls or uploads.

## Scope

- Add provider availability/capability/status models to the formula OCR provider contract.
- Have the production unavailable provider declare that live formula OCR is not configured.
- Have the manual provider declare that local user-entered LaTeX is available without credential or network use.
- Surface provider status in Reconstruction workspace UI state and screen content.
- Add JVM contract tests and Compose fixture coverage for provider status.

## Out of Scope

- Live Mathpix provider implementation.
- PaddleOCR/pix2tex bundling or model execution.
- Credential storage, backend proxy, network upload or cloud processing.
- Changing formula processing queue behavior.
- Connected device execution against protected physical hardware.

## Validation

- JVM tests and androidTest Kotlin compile.
- Lint and internal APK build.
- Signature/hash/secret/cache checks before commit.
