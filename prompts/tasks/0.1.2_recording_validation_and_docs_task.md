- 检查 `adb devices -l` 和可用 Android device/emulator。

- 验证 `RECORD_AUDIO` permission flow。

- 验证 End Seminar 后 notification 消失、Room recording 为 `COMPLETED`、seminar 为 `COMPLETED`、`.m4a` 文件存在。
