## 修复内容

本轮 Emulator regression 暴露并修复了真实 app/test 问题：

1. Room migration instrumentation 首次在 Emulator 上失败，因为 migration schema asset 未打进 androidTest assets；已将 `app/schemas` 加入 `androidTest` assets。
2. `SeminarDetailViewModel.onOpenTimelineClicked()` 使用 `MutableSharedFlow.tryEmit()`，在无 buffer 的 UI event flow 上会静默丢失导航事件；已改为 `viewModelScope.launch { emit(...) }`，并补充 ViewModel test。
3. Detail 页面使用不可滚动的普通 `Column`，导致 Export/Delete 在 Emulator 视口底部不可达；已改为 `verticalScroll(rememberScrollState())`，并补充 Compose instrumentation 断言 `Share ZIP` 可滚动到可见。
4. Windows unit test 暴露 fake storage path 使用硬编码 Unix 分隔符；已改为平台无关的 `File` 断言。
