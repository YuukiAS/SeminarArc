# 0.5.x Formula Schema Domain Task

## Objective

Add the local Room/domain foundation for formula-aware reconstruction without enabling live formula OCR, cloud upload, paid providers, backend, or connected-device automation.

## Scope

- Add Room entities for formula regions and formula OCR results.
- Bump Room schema from v6 to v7 with explicit `MIGRATION_6_7`.
- Export checked-in Room schema `7.json`.
- Add a DAO boundary for observing and mutating formula regions/results.
- Add domain models for formula regions, formula result state, and formula results.
- Extend `ProcessingJobType` with `FORMULA_OCR` while keeping existing Worker/scheduler behavior safe until the provider queue task wires it.
- Update architecture/privacy/roadmap docs and write this result file.

## Out of Scope

- No formula region selection UI.
- No formula OCR provider implementation.
- No Mathpix/PaddleOCR/pix2tex runtime integration.
- No private credential, backend, external upload, account creation, production signing, or Google Play action.
- No connected Android tests, APK installation, app launch automation, physical-device command, ADB transport reset, or usbipd/WSL manipulation.

## Verification

- Run headless JVM/build checks with Gradle/Android homes on `D:\`.
- Compile Android test sources so migration test code and schema assets remain buildable.
- Do not run connected tests unless Windows ADB sees only expected `emulator-*` devices.
