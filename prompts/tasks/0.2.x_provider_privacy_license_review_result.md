# 0.2.x Provider Privacy License Review Result

## Provider boundary

`0.2.x` 实现真实 provider：

- `TextOcrProvider`
- `ImageEnhancementProvider`
- `CloudUploadPolicy`

只定义接口或 sealed policy，不实现真实处理：

- `FormulaOcrProvider`
- `TranscriptionProvider`
- `SummaryProvider`
- `ReferenceLookupProvider`

## 边界规则

- Compose UI 不直接调用 provider。
- ViewModel 只调用 repository/use case。
- Worker/use case 调 provider，结果映射为 app-owned domain model 与 Room row。
- `processing_jobs.providerId` / `providerVersion` 记录实现来源，但数据库不保存 ML Kit private response 作为唯一事实。
- Cloud upload 默认 `DISALLOWED_BY_DEFAULT`；0.2.x 没有任何自动上传路径。

## License / privacy

- ML Kit Text Recognition bundled artifacts 可作为第一版 OCR 候选，但必须披露 SDK diagnostics/usage metrics 数据收集；用户 seminar 图片/输出不上传给 Google。
- Android platform Bitmap/Matrix/ColorMatrix 属于 Android SDK/API 使用，无新增第三方 runtime SDK。
- OpenCV 暂不引入；已确认 OpenCV 4.5+ 为 Apache 2.0，Maven Central Android AAR 从 4.9.0 起可用，后续引入时需要保留 license notice。

## Privacy copy requirements

`docs/PRIVACY.md` 和 UI 文案需要区分：

- Local OCR: 在设备端处理 seminar photo，不需要 API key，不上传照片；但 ML Kit SDK 可能发送 diagnostics/usage metrics。
- Future cloud OCR/transcription/summary/reference lookup: 必须用户主动选择，显示 provider、资产范围、费用/配额和删除语义。

## Gate

无需要用户产品决策的冲突。Phase B 可按上述 provider boundary 进入实现。
