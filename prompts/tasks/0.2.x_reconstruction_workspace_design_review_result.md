# 0.2.x Reconstruction Workspace Design Review Result

## 结论

`Research Reconstruction` 第一版作为 completed seminar detail 的会后整理工作区，不替代统一 timeline，也不进入 0.3.x reference lookup。

## 更新范围

- `design/README.md` 新增 0.2.x workspace 说明。
- `design/UI_SPEC.md` 新增 Research Reconstruction 页面、状态、组件和禁止事项。
- `design/USER_FLOW.md` 新增会后视觉重建流程。

## UI 决策

- Completed seminar detail 显示 `Research Reconstruction` 主入口。
- Workspace 顶部持续显示 seminar identity。
- 内容分为 photo rail、selected slide workspace、OCR review panel、tags/key slide controls、processing queue。
- OCR 状态必须区分 pending/running/succeeded/failed/cancelled。
- 原图/增强图使用 segmented toggle。
- OCR 文本可编辑，人工编辑后显示 edited state。
- Tags/key slide、OCR status、search 都是 seminar-scoped。
- Future transcript/reference/AI 只能显示 disabled/coming later，不得伪装完成。
