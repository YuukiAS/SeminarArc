## Provider 结论

| Provider | 0.3.x 角色 | 理由 |
| --- | --- | --- |
| Crossref | Primary | DOI-first 和 bibliographic lookup 最贴合第一版；无需 signup；允许/建议缓存；有明确 polite pool/rate-limit 行为。 |
| OpenAlex | Secondary / cross-confirmation | 覆盖更广、CC0、works graph 丰富，适合作 fallback 和 provider agreement，不必让每个 noisy OCR query 都依赖它。 |
| DataCite | Targeted fallback | dataset/software/non-Crossref DOI 线索时补足 DataCite DOI metadata。 |
| Semantic Scholar | Deferred | API/data license 对商业用途和公开展示有额外约束；默认生产接入前需要明确法律/产品批准。 |

## Evidence Extraction 设计

- 只使用用户选择的 OCR text、`KEY_SLIDE`/`REFERENCE` tag photo OCR、seminar metadata、手工 DOI/title/author/year clue、用户选择的 question/note。
- 不默认上传全部 seminar OCR、照片、录音、timeline、Markdown/ZIP 或 app-private path。
- DOI regex：case-insensitive `\b10\.\d{4,9}/[-._;()/:A-Z0-9]+\b`。
- DOI normalization：清理 `doi:`、`https://doi.org/`、`dx.doi.org`、括号、尾部标点、OCR line wrap 和常见 `O/0`、`I/l/1` 错误候选。
- 无 LLM 的 title/author/year/venue heuristic 只生成候选 clue；低质量 OCR 或冲突 clue 必须人工确认。

## Candidate Ranking / Dedup 设计

- exact normalized DOI lookup 最高优先，作为 `HIGH_CONFIDENCE` override。
- 非 DOI 查询使用透明 100 分 match score：title similarity 35、author overlap 20、year proximity 10、venue 10、provider cross-confirmation 10、evidence quality 10、query type bonus 5。
- UI 只显示 `HIGH_CONFIDENCE`、`POSSIBLE_MATCH`、`NEEDS_REVIEW`，不展示伪精确概率。
- Dedup 先按 normalized DOI，再按 normalized title + year + first-author overlap。
- 多 provider 结果合并时保留 provenance 和 match reasons。

## Privacy / Network Contract

- 用户显式触发 lookup。
- 联网前显示 query preview。
- 默认只发送 DOI 或选定 bibliographic clue。
- 不发送照片、录音、clips、abstract PDF、完整 OCR、完整 timeline 或 export archive。
- 处理 429、timeout、offline 和 provider unavailable；这些状态不阻塞本地 Reconstruction。
- provider cache 与 seminar 绑定，删除 seminar 时清理。
- 不嵌入 paid/provider API secret。

## UX 设计

Flow:

```text
Research Reconstruction
  -> select evidence
  -> Find references
  -> Query preview
  -> Lookup
  -> Candidate Review
  -> Confirm / Reject
  -> Seminar Brief
  -> Markdown/ZIP export
```

Candidate Review 保持列表优先、seminar-scoped、match reason 可见。Seminar Brief 是用户编辑的 app-owned document，不是 AI output。
