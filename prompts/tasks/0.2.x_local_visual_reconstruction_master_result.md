# 0.2.x Local Visual Reconstruction Master Result

## 总结

`0.2.x` Local Visual Reconstruction 已完成。SeminarArc 现在具备本地视觉重建闭环：Room v3 asset/job/OCR/tag schema、本地图像增强、bundled ML Kit 普通 OCR、OCR 搜索/标签/key-slide、WorkManager-backed processing queue、Reconstruction workspace，以及 Windows Emulator closeout evidence。

## Readiness decisions

- Room 从 version `2` 显式迁移到 version `3`。
- OCR 使用 bundled ML Kit Text Recognition v2 Latin + Chinese artifacts，不使用首次离线可能失败的 unbundled Play Services model download 路径。
- 图像增强使用 Android native `Bitmap` / `Matrix` / `Canvas` / `ColorMatrix`，本阶段不引入 OpenCV。
- `TextOcrProvider`、`ImageEnhancementProvider` 和 `CloudUploadPolicy` 是 `0.2.x` 的 provider/privacy 边界。
- `FormulaOcrProvider`、`TranscriptionProvider`、`SummaryProvider`、`ReferenceLookupProvider` 的真实能力不进入 `0.2.x`。
- Cloud upload 默认禁止；`0.2.x` 不上传 seminar photo、recording 或 OCR text。

## Schema / migration

- `AppDatabase` version `3`。
- 新增 `seminar_assets`、`processing_jobs`、`ocr_results`、`tags`、`asset_tags`。
- `MIGRATION_2_3` 保留 `seminars`、`recordings`、`timeline_events`、`audio_clips`，并从旧路径 backfill abstract、recording、photo、clip assets。
- Windows Emulator connected test 已真实执行 `MIGRATION_2_3` 并 PASS。

## ProcessingJob / WorkManager

- 新增 `ProcessingWorkScheduler`、`WorkManagerProcessingWorkScheduler`、`ProcessingWorker`。
- OCR 与 image enhancement 现在通过 WorkManager queue 执行，worker input 以 job ID 为核心，执行时重新读取 Room/storage/provider。
- 支持 durable `QUEUED/RUNNING/SUCCEEDED/FAILED/CANCELLED`。
- 支持 duplicate active job idempotency、retryable failed/cancelled retry、queued/running cancel、partial enhanced output cleanup。
- App process start 会恢复 queued/running job：orphan `RUNNING` 还原为 `QUEUED` 并重新 enqueue。

## Local image enhancement

- 支持 rotate、crop、manual perspective correction、readability enhancement。
- Enhanced photo 作为 `PHOTO_ENHANCED` derived asset 保存，原图始终保留。
- Emulator smoke 已验证 derived JPEG 可读、original 可读、missing source failure 不创建 output。

## Local OCR

- bundled ML Kit Latin / Chinese recognizer 已接入真实 Android runtime。
- Emulator smoke 已验证 Latin、Chinese、mixed Chinese/English、empty/low-text 和 missing asset failure。
- WorkManager queue smoke 已验证 OCR duplicate request、retry failure、Room result persistence。

## Search / tags / key slide

- Reconstruction workspace ViewModel 组合 photo assets、OCR results、processing jobs、KEY_SLIDE tag、search query 和 OCR status filters。
- 支持 OCR text search、HAS_OCR / NEEDS_OCR / FAILED filtering、KEY_SLIDE toggle 和 key-slide-only filter。
- OCR edit 保留 recognized text，并写入 edited text state。

## Reconstruction workspace

- Completed seminar detail 可进入 `Research Reconstruction`。
- Workspace 显示 photo preview、search/filter、key-slide toggle、enhance/OCR actions、OCR edit，以及 processing queue Retry/Cancel。
- Compose 不直接访问 Room、WorkManager、ML Kit、CameraX、recorder 或 storage provider。
- Connected UI regression 已覆盖 queued/running/failed/cancelled processing controls。
