# 0.4.x Summary Draft Edit Task

## Objective

Add a local summary draft editing loop so generated or queued draft records can become user-owned editable brief material before live summary providers are configured.

## Scope

- Let Transcript Review edit all existing summary draft prose fields.
- Persist edits through `TranscriptRepository`.
- Mark saved edited records as `DRAFT` and clear provider error text while preserving provider id, input fingerprint, provenance JSON, and created time.
- Keep edited drafts available to existing Markdown/ZIP export and Notion-ready export contract paths.

## Out of Scope

- No live LLM provider.
- No Notion OAuth/upload.
- No backend, token storage, private credential, or recurring-cost service.
- No connected Android test or APK installation while Windows ADB can see protected physical device serial `8cc54656`.

  - `.\gradlew.bat --no-daemon lintDebug assembleInternal`
