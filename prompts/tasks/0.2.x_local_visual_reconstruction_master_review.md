# 0.2.x Local Visual Reconstruction 当前进度 Review

## 结论

当前 `0.2.x` 已完成 readiness gate 与 Phase B-F 的第一轮 production foundation，但尚不能声明 `0.2.x COMPLETE`。

当前状态应理解为：

- Phase A Readiness：PASS。

## 已有证据

- Readiness plan 已标记 `readiness gate passed`。

## 尚未闭环的问题

### 1. ProcessingJob 目前主要是 durable state foundation，缺少完整后台队列闭环

现有 OCR/image enhancement result 明确记录：WorkManager/worker queue integration 尚未接入。

Master contract 要求 OCR / enhancement 至少满足：

- cancel；
- retry；
- idempotency；
- process recreation/restart 后可恢复；
- 重复请求不会无限创建 job；
- UI 能真实反映 queued/running/failed/cancelled/succeeded。

因此不能仅凭同步 use case + job row 就把 0.2.x processing lifecycle 视为完成。

### 2. v2->v3 migration 尚缺 Windows Emulator connected execution evidence

migration instrumentation test 已写，但当前 0.2.x 提交后的 Windows Emulator `connectedDebugAndroidTest` 尚未执行。

需要在已验证的 Windows `Pixel_8 / API 36 / emulator-5554` 上真实 install / execute / PASS。

### 3. bundled ML Kit OCR 尚缺 Emulator 真实运行 evidence

需要至少覆盖：

- Latin；
- Chinese；
- mixed Latin/Chinese；
- empty/low-text；
- missing asset；
- duplicate request；
- retry/cancel；
- app/process reopen 后结果持久化。

不要求 OCR benchmark，但必须证明 production provider 能在 Android runtime 实际运行，而不是只有 JVM fake/provider boundary 测试。

### 4. 图像增强尚缺 Emulator smoke

至少验证：

- rotate/crop/perspective/readability pipeline 能真实处理 bitmap；
- derived image 可读；
- original 仍可读；
- failure 不覆盖原图；
- retry/idempotency 行为成立。

### 5. Reconstruction workspace 缺 connected/UI regression

需要验证：

- Detail -> Reconstruction navigation；
- photo preview；
- OCR search/filter；
- key-slide toggle；
- enhance/OCR action；
- OCR edit persistence；
- retry/cancel processing state；
- app restart 后 state persistence；
- 0.1.x timeline/playback/export 不回归。

### 6. 文档存在一个明显陈旧点

当前 README 已声明 0.2.x OCR foundation 已实现，但后面的“当前明确不做”仍写着 `OCR`，这是 0.1.x 时期遗留表述，应在 0.2.x closeout 中修正为只禁止 transcription / AI / cloud / reference lookup 等尚未实现能力。

### 7. Master result 尚不存在

`prompts/tasks/0.2.x_local_visual_reconstruction_master_result.md` 尚未创建，因此 master goal 还没有正式收口。
