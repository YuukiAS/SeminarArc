# 0.2.x Reconstruction Schema Design Result

## 当前 schema 事实

- `AppDatabase` 当前版本为 `2`。
- 现有表保留：`seminars`、`recordings`、`timeline_events`、`audio_clips`。
- 现有媒体事实分布：
  - abstract PDF：`seminars.abstractPdfPath`
  - recordings：`recordings.filePath`
  - photos：`timeline_events.photoPath` with `type = PHOTO`
  - clips：`audio_clips.filePath`
- 现有 seminar-owned file layout 为 `files/seminars/<seminar-id>/abstract|recordings|photos|clips`。

## 0.2.x migration 决策

下一版 Room migration 为显式 `MIGRATION_2_3`，不使用 destructive migration。

新增表：

- `seminar_assets`
  - `id INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL`
  - `seminarId INTEGER NOT NULL`
  - `type TEXT NOT NULL`
  - `originAssetId INTEGER`
  - `sourceTimelineEventId INTEGER`
  - `sourceRecordingId INTEGER`
  - `sourceClipId INTEGER`
  - `relativePath TEXT`
  - `mimeType TEXT`
  - `displayName TEXT`
  - `createdAt INTEGER NOT NULL`
  - `updatedAt INTEGER NOT NULL`
  - indices: `seminarId`, `type`, `originAssetId`, `sourceTimelineEventId`
  - FKs: seminar cascade; origin asset set-null; timeline/recording/clip set-null
- `processing_jobs`
  - durable local job table for enhancement/OCR.
  - state enum: `QUEUED`, `RUNNING`, `SUCCEEDED`, `FAILED`, `CANCELLED`。
  - records provider id/version, job type, input asset, optional output asset, timestamps, retry count, retryable flag, readable error.
- `ocr_results`
  - one latest app-owned OCR result per photo/enhanced asset, plus edited text.
  - stores `recognizedText`, optional lightweight block JSON, `languageHint`, `confidence`, provider id/version, `isEdited`, timestamps.
- `tags`
  - system tags plus custom tags.
- `asset_tags`
  - many-to-many mapping with unique `(assetId, tagId)`。

暂不在 `0.2.x` 创建真实 `TranscriptSegmentEntity`、`ReferenceCandidateEntity`、`FormulaOcrProvider` 结果表；只通过 provider boundary 和 job type 预留命名空间，避免提前进入 `0.3.x`。

## Backfill

`MIGRATION_2_3` 应幂等 backfill:

- 对 `seminars.abstractPdfPath IS NOT NULL` 创建 `ABSTRACT_PDF` asset。
- 对每条 `recordings.filePath` 创建 `RECORDING` asset。
- 对每条 `timeline_events.type = PHOTO AND photoPath IS NOT NULL` 创建 `PHOTO_ORIGINAL` asset。
- 对每条 `audio_clips.filePath IS NOT NULL` 创建 `AUDIO_CLIP` asset。

Backfill 使用 `INSERT OR IGNORE` 加唯一约束避免重复。现有路径字段暂保留为 0.1.x 兼容事实，不在 migration 中清空或移动。

## 失败保护

- Migration 只新增表、索引、nullable columns 和 backfill rows，不重写或删除现有媒体路径。
- Backfill 失败应回滚 Room migration transaction，不产生部分 schema。
- 文件迁移不放进 Room migration；派生资产文件由后续 repository/job 管线创建。

## 测试策略

- JVM: schema/entity/repository tests 覆盖 asset/job/OCR/tag DAO。
- Instrumentation: 从 schema `2.json` migration 到 v3，验证旧 seminar、recording、photo timeline、clip row 仍存在，且 backfilled asset row 数量正确。
- Export regression: v3 后 `SeminarExportAssembler` 仍可从旧路径导出 0.1.x 内容。
