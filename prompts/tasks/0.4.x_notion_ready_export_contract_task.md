# 0.4.x Notion-Ready Export Contract Task

## Objective

Add a local Notion-ready export contract that can represent SeminarArc export content as provider-neutral blocks without enabling Notion OAuth, API calls, upload, backend deployment, private credentials, or recurring-cost services.

## Scope

- Map `SeminarExportDocument` into a local block-like structure suitable for future Notion page/block creation.
- Preserve seminar metadata, abstract, recording summary, transcript review content, timeline windows, generated summary drafts, brief sections, references, key slides, timeline items, and local relative media paths.
- Provide a Markdown preview for the Notion-ready structure so the contract is inspectable without a live Notion account.
- Add focused JVM tests for transcript/summary/media coverage and the upload-free local preview claim.

## Out of Scope

- No Notion OAuth.
- No Notion API client.
- No token storage.
- No file upload.
- No backend.
- No live provider smoke.
- No connected Android test or APK installation while Windows ADB can see protected physical device serial `8cc54656`.
