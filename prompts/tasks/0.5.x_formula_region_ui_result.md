# 0.5.x Formula Region UI Result

## Status

`COMPLETE`

## Changes

- Added `FormulaRepository` and `FormulaRepositoryImpl`.
- Region creation now verifies the source asset belongs to the same seminar, is `PHOTO_ORIGINAL` or `PHOTO_ENHANCED`, and has a non-blank local relative path.
- Reconstruction workspace now observes formula regions and groups them by photo asset.
- Photo cards show saved formula regions and expose local create/delete actions.
- Added a compact normalized crop form for formula label, x, y, width, and height.
- Added ViewModel actions for creating and deleting formula regions.
- Updated Android Compose test fixtures and added callback coverage for formula region controls.
