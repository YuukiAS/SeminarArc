# 0.1.3 Capture Timeline Result

## 完成内容

- 实现 app-private photo 输出路径：`files/seminars/<seminarId>/photos/photo-<timestamp>.jpg`。
- 实现 `TimelineRepository` 写入和删除路径，支持 `MARK`、`PHOTO`、`QUESTION`、`NOTE`，并在删除 photo event 时一致清理 app-owned photo 文件。
- 实现 offset 计算：录音模式使用 recording start，photos-only 使用 seminar session start，并对时钟回退 clamp 到 `0`。
- 实现 Active Session 现场采集 UI：CameraX preview/capture、mark、question、quick note、last photo feedback、undo、retake。
- 实现 Seminar Detail 的 photos-only 启动入口；该入口只启动 ACTIVE seminar session，不请求 microphone permission、不启动 foreground recorder。
- 实现统一 Timeline route：按 offset 混排事件，显示 photo preview 或 missing/unreadable 状态，有可读 completed recording 时支持 `Play from here`。
- 保持 `0.1.x` 禁止范围：未加入 OCR、转写、AI、Notion、云同步、登录、广告、订阅、支付。
