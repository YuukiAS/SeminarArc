# 0.2.x Local Image Enhancement Result

## Summary

Implemented the first production local image enhancement foundation for `0.2.x`.

## Delivered

- Added `ImageEnhancementProvider` and enhancement option models for rotation, fractional crop, fractional perspective correction, readability enhancement, and JPEG quality.
- Added `AndroidBitmapImageEnhancementProvider`, using Android local `Bitmap`, `Matrix`, `Canvas`, and `ColorMatrix` APIs.
- Extended `MediaStorageManager` with deterministic enhanced photo outputs under each seminar's app-private `enhanced/` directory.
- Added `EnhancePhotoAssetUseCase` to resolve app-owned source files, preserve originals, create `PHOTO_ENHANCED` derived assets, and update durable `IMAGE_ENHANCEMENT` processing jobs.
- Added repository lookup by relative path to support idempotent same-variant enhancement.
- Added JVM tests for success, original preservation, same-variant idempotency, provider failure, retryable job failure, and partial-output cleanup.
