# 0.4.x Transcript Review UI Task

## Objective

Add the first user-facing transcript review surface for `0.4.x` without enabling live transcription, live summary generation, cloud upload, or Notion integration.

## Scope

- Add a type-safe navigation route for transcript review.
- Add a Reconstruction workspace entry point.
- Add `TranscriptReviewViewModel` backed by `SeminarRepository`, `TranscriptRepository`, and `BuildTranscriptTimelineWindowsUseCase`.
- Display transcript list, selected transcript metadata, timestamped segments, timeline-linked transcript windows, and summary draft status.
- Keep provider actions as explicit not-yet-wired messages rather than fake live processing.
- Keep the UI local-first and read-only for transcript/summary content in this task.
- Update androidTest compilation coverage for the new Reconstruction entry point.

## Out of Scope

- No live ASR provider selection or execution.
- No live `SummaryProvider` execution from UI.
- No segment text editing yet.
- No Notion OAuth/upload.
- No connected Android test execution or APK installation while Windows ADB can see protected physical device serial `8cc54656`.

- Run headless Gradle verification with D-drive local homes:
  - `.\gradlew.bat --no-daemon testDebugUnitTest compileDebugAndroidTestKotlin`
  - `.\gradlew.bat --no-daemon lintDebug assembleInternal`
- Verify the internal APK with `apksigner`.
