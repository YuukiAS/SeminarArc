# 0.5.x Formula Provider Contract Result

## Status

`COMPLETE`

## Changes

- Added `FormulaOcrProvider` domain contract.
- Added request models for seminar id, formula region id, source asset id, local source photo handle, normalized crop, rotation, language/context hint, request fingerprint, and optional manual LaTeX.
- Added result models for recognized LaTeX, confidence, provenance JSON, failure message, and retryability.
- Added `ManualFormulaProvider` for explicit user-supplied LaTeX with generated non-sensitive provenance JSON.
- Added `UnavailableFormulaOcrProvider` as the production Hilt default so formula OCR cannot silently pretend a live provider exists.
- Added `FormulaOcrProviderContractTest` covering fake provider round-trip, manual provider trimming/provenance, unavailable failure, identity/fingerprint validation, crop bounds, LaTeX blank rejection, and confidence bounds.
