# 0.4.x Transcript Review Queue Entry Task

## Objective

Connect the transcript review screen's transcription action to the durable `TRANSCRIPTION` queue without enabling a live ASR provider.

## Scope

- Inject `RecordingRepository` and `ProcessingWorkScheduler` into `TranscriptReviewViewModel`.
- When the user taps the transcription action, find the latest completed recording for the seminar.
- Enqueue a durable transcription job through `ProcessingWorkScheduler.enqueueTranscription`.
- Show clear snackbar feedback for missing completed recordings, enqueue failure, and queued jobs.
- Update copy so the UI advertises durable queue preparation rather than fake provider execution.

## Out of Scope

- No live provider picker.
- No live ASR provider.
- No cloud upload.
- No transcript segment editing.
- No connected Android test or APK installation while Windows ADB can see protected physical device serial `8cc54656`.

  - `.\gradlew.bat --no-daemon lintDebug assembleInternal`
