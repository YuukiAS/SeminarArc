# 0.1.x Windows Emulator Onboarding And Regression Task

## 目标

在 Windows 原生 Codex 环境中建立 SeminarArc 的 Windows Emulator connected-test 默认链路，替代此前无法从 WSL 进入 Windows Emulator 的 onboarding 阻塞。

本 task 不恢复旧的物理真机 acceptance goal。GM1910 / OnePlus 7 Pro / serial `8cc54656` 仅做开始和结束的 `usbipd list` 只读状态记录，严禁任何 ADB shell/install/input、ADB transport 或 usbipd attach/detach/bind/unbind 操作。

## 当前环境事实

- Windows Android SDK：`D:\Android\Sdk`
- Android Emulator：`D:\Android\Sdk\emulator\emulator.exe`
- Windows ADB：`D:\Android\Sdk\platform-tools\adb.exe`
- Android Studio JBR：`C:\Android\Android Studio\jbr`
- Windows test mirror：`D:\Code\SeminarArc-emulator`
- WSL canonical repo：`/home/yuukias/code/SeminarArc`
- GitHub bridge：`https://github.com/YuukiAS/SeminarArc`

## 已确认 Emulator

- AVD name：`Pixel_8`
- Emulator serial：`emulator-5554`
- Model：`sdk_gphone64_x86_64`
- API：`36`
- ABI：`x86_64`
- Acceleration：`WHPX(10.0.26100) is installed and usable`
- Boot completed：`sys.boot_completed=1`

## 安全边界

- connected/instrumentation tests 只能在 `emulator-*` 上运行。
- 每次 connected test 前必须执行 `D:\Android\Sdk\platform-tools\adb.exe devices -l`。
- Windows ADB 不得出现 `8cc54656`、GM1910 或其他 physical USB device。
- 如果 Windows ADB 看见 physical device，记录 `WINDOWS_ADB_PHYSICAL_DEVICE_VISIBLE`，停止 connected regression，但继续安全的 JVM/build/lint/docs 工作。
- 不共享 WSL/Windows Android SDK、Gradle cache、JDK 或 ADB server。

## 执行范围

1. 使用 Windows mirror 跑 `testDebugUnitTest`、`assembleDebug`、`lintDebug`。
2. 在 Windows ADB safety gate 通过后跑 `connectedDebugAndroidTest`。
3. 确认 `MIGRATION_1_2` 相关 instrumentation test 在 Emulator 上 install、execute、PASS。
4. 安装/启动 debug app 并做 Emulator smoke：list、create/open seminar、detail、active session、timeline/review、export UI、Room reopen persistence、permission UI 不 crash。
5. 若 Emulator 暴露真实 app/test bug，正常修复并重跑验证。
6. 写回本 task result、更新 `docs/DEVICE_TESTING.md`、`AGENTS.md`、`prompts/tasks/0.1.x_local_mvp_completion_master_result.md`。

## 预期结果

- 若完整通过，记录 `EMULATOR_REGRESSION_PASS`。
- 物理硬件验收继续保持 `DEFERRED / NOT A DAILY DEVELOPMENT BLOCKER`。
- Emulator camera/microphone evidence 不等价于 physical hardware acceptance。
