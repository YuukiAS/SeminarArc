## Audit Findings

### Build / CI

- `app/build.gradle.kts` 使用 `compileSdk = 36`、`targetSdk = 36`、`minSdk = 26`，与本机 SDK `platforms;android-36`、`build-tools;36.0.0` 对齐。
- `.github/workflows/android.yml` 在 push / pull_request 上执行 debug build 和 unit tests，不是空壳。
- 原有 Kotlin warning 已处理：AutoMirrored back icon 和 `ExperimentalCoroutinesApi` opt-in。
- 非阻断环境 warning：SDK XML version warning、strip debug symbols warning。两者不阻断 build。

### Room / Repository / Storage

- 核心实体和枚举存在，且 `recordings`、`timeline_events`、`audio_clips` 都通过 `seminarId` 关联 seminar。
- `TimelineEventEntity` 包含 `offsetMs`，支持后续可恢复 offset。
- `AudioClipEntity` 包含 `PENDING | PROCESSING | READY | FAILED` 所需字段。
- `SeminarDao` list/detail 查询提供 photo count、clip count、最新 recording duration 和 timeline preview。
- 已移除 destructive migration，避免未来真实用户数据被误清空。
- 已修复 PDF 替换失败路径：导入失败不删除旧文件；DB 更新失败会删除新文件并保留旧路径。

### UI / Placeholder / Accessibility

- List/editor/detail 通过 ViewModel -> repository 访问数据，没有发现 composable 直接访问 Room 或平台 recorder/camera API。
- Seminar list 保持列表优先，没有 dashboard 化。
- Editor 使用 `ACTION_OPEN_DOCUMENT` 选择 PDF，并通过 ViewModel/repository/storage 路径保存。
- Detail 中 `Start seminar (0.1.2)` 是 disabled button，并配有明确 later-batch 文案，没有伪装录音可用。
- Timeline preview 空状态明确说明 recording/mark/note/question/photo flows 在 later batches。
- 主要 IconButton、Button、OutlinedButton 使用 Material 组件，默认满足 48dp touch target；图标按钮有 content description。仍建议后续 UI 验收时用真实大字体截图复核。

### Docs / Design

- `README.md` 准确声明当前是 `0.1.1-dev`，并明确尚未完成 recording、CameraX、timeline event、clip、export。
- `docs/ARCHITECTURE.md` 与当前单模块 layered 架构一致。
- `docs/PRIVACY.md` 没有声称已实现录音/相机，只说明当前本地存储和未来批次。
- `design/README.md` 的 Windows 绝对链接已改成相对链接。
