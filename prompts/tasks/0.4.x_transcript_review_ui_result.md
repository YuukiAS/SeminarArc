## Status

Implemented.

## Changes

- Added `TranscriptReviewRoute`.
- Added `TranscriptReviewUiState` and `TranscriptReviewEvent`.
- Added `TranscriptReviewViewModel`.
- Added `TranscriptReviewScreen`.
- Added a `Review transcripts` entry point from Reconstruction workspace.
- The screen shows:
  - available transcript providers/states,
  - selected transcript metadata,
  - timestamped transcript segments,
  - timeline/photo transcript windows from `BuildTranscriptTimelineWindowsUseCase`,
  - summary draft statuses.
- Provider actions currently emit clear not-yet-wired messages instead of pretending that live ASR or summary providers are available.
- Updated `ReconstructionWorkspaceScreenTest` compile coverage for the new entry point.

## Privacy / Scope Boundary

- This UI reads existing local Room/domain data only.
- No transcript text, photos, recordings, OCR corpus, notes, summary drafts, or app-private paths are uploaded.
- No live ASR provider, live LLM summary provider, Notion OAuth/upload, backend, private credential, or recurring-cost service was added.
