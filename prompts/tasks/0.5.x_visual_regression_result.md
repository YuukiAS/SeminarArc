# 0.5.x Visual Regression Result

## 结论

本任务通过。SeminarArc 已建立首套受控的 screenshot golden baseline：共 5 个显示 profile、33 个稳定 UI 状态。所有 golden 都来自本任务期间在 `emulator-5554` 上通过的 package-level black-box 运行，并在接受前逐张打开检查。

baseline 位于 `scripts/visual-baselines/0.5.x/`。普通运行只比较 candidate，不会修改 baseline；首次接受或后续更新都必须使用显式开关。tracked manifest 只记录 profile、scenario、状态标签、相对 PNG 路径和 viewport，不包含 `private` 路径、真实 seminar 内容或 UI tree 私有证据。

## 目检结论

- 33/33 screenshot 已逐张打开检查。
- 标题校验错误在 normal、small 和 1.3× 字号下都回到可见区域。
- 小屏 filter row 可横向滚动；空库主体可纵向滚动，CTA 不再因短 viewport 不可达。
- 长 OCR、Transcript 和 formula edit 在 small、large-font、landscape 与 tablet profile 下均可通过滚动访问，没有出现字段互相覆盖或无法恢复的横向溢出。
- landscape 截图保留短 viewport 的局部滚动状态；这是当前滚动位置，不是内容层互相遮挡。
- tablet 当前仍是可用的单列宽屏布局，本任务没有把它描述为已完成双栏或专用大屏信息架构。
- Android document picker 属于 API 36 Emulator 系统 UI；它被纳入当前 baseline，但不代表其他 Android 版本的系统 picker 像素级一致。

## 修复与基础设施

- `SeminarEditorScreen` 记住 scroll state；保存失败出现 `errorMessage` 时自动回到顶部，让 `Title is required.` 在小屏上可见。
- 空 library 主体改为可滚动，filter row 改为横向可滚动，避免短屏和窄屏内容不可达。
- OCR edit 成功后发送 `OCR result saved.`，使 UI automation 能以真实 Room 更新结果作为持久化边界，而不是只依赖点击动作。
- black-box harness 改为读取当前 viewport/rotation，使用避开可拖拽照片区域的安全手势，并加强双向滚动、系统 picker、键盘关闭、OCR focus、公式编辑和重启持久化判断。
- 修正重定向子进程 stdout/stderr 的读取顺序，避免 Gradle 输出填满 pipe 后与 `WaitForExit` 互相等待。
- 新增 `scripts/run-visual-regression.ps1` 和 `scripts/blackbox/Compare-VisualGolden.py`：profile 配置通过 `finally` 恢复；candidate/diff 保存在 ignored private 目录；baseline 写入需要显式 `-AcceptInitialBaseline` 或 `-UpdateBaseline`。
