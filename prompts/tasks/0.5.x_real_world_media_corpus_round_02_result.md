## Harness 修复

- 支持按 `round-*` 子目录递归选择照片、PDF 和录音，同时兼容旧的平铺目录。
- 新增录音 inventory 与 Windows Shell 元数据读取；录音不进入不存在的产品导入路径。
- 运行 ID 加入毫秒和进程 ID，避免并行或快速重跑时证据目录冲突。
- 修正 OCR 文本框定位：`OCR text` 是 `EditText` 的子语义节点，不能按“标签下方第一个输入框”查找。
- 不再使用文件名编号测试 OCR 搜索。搜索只验证真实 OCR/人工编辑文本；样本卡片通过未筛选列表定位。
- 列表纵向手势移到卡片左侧安全留白，避免被可拖拽公式图片截获。
- 先完成全部照片核心处理，最后执行公式代表流程，避免展开的公式编辑区阻塞后续样本。
- 系统文件选择器会记住上次嵌套目录；确定性 harness 现在通过 `Show roots` 精确返回 `Downloads`。
- 持久化检查从抽查 3 张收紧为 9/9，并将缺失素材升级为整轮失败。
