## Privacy Boundary

- Reference lookup is opt-in and user-triggered.
- The provider request sends only selected DOI/title/author/year/venue metadata or selected OCR text snippets.
- The implementation does not send seminar photos, recordings, complete OCR corpus, timeline, export archives, app-private file paths, transcription, AI summary, Notion payloads, formula OCR data, or private API keys.
- Live provider smoke used fixed public fixtures only.
