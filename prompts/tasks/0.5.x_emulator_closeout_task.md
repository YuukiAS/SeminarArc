# 0.5.x Emulator Closeout Task

## Goal

Run the `0.5.x` connected Emulator closeout only if Windows ADB isolation is safe, then decide whether `v0.5.0-alpha.1` can proceed.

## Scope

- Run Windows ADB preflight with D-drive temporary Android home.
- Proceed to connected Emulator regression only if ADB sees exactly the intended `emulator-*` target and no protected physical serial.
- If protected physical serial is visible, record the gate as deferred and stop connected execution.

## Out of Scope

- Physical device install, shell/input, instrumentation or recovery.
- `adb kill-server`, reconnect, usbipd attach/detach/bind/unbind, WSL shutdown or transport reset.
- Creating `v0.5.0-alpha.1`, pushing tags, triggering GitHub Actions or creating Release assets before connected gate passes.

## Validation

- `D:\Android\Sdk\platform-tools\adb.exe devices -l` with temporary D-drive home.
