# 0.4.x Notion-ready Save Entry Task

## Objective

Expose the existing local Notion-ready Markdown preview through Android document save flow.

## Scope

- Add a `SeminarExportRepository` write method for Notion-ready Markdown preview text.
- Use `SeminarNotionReadyRenderer.renderMarkdownPreview` from the existing local export document.
- Add a Seminar Detail export action that saves the preview via `ACTION_CREATE_DOCUMENT` as `text/markdown`.
- Keep the feature local, explicit, and upload-free.

## Out of Scope

- No Notion OAuth.
- No Notion API client.
- No token storage, backend, private credential, or recurring-cost service.
- No automatic upload to Notion or any third-party provider.
- No connected Android test or APK installation while Windows ADB can see protected physical device serial `8cc54656`.

  - `.\gradlew.bat --no-daemon testDebugUnitTest compileDebugAndroidTestKotlin`
  - `.\gradlew.bat --no-daemon lintDebug assembleInternal`
