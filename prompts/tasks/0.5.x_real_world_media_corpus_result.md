## Bugs Fixed

- Real OCR output could expand the Reconstruction card so far that subsequent
  photos became impractical to reach in multi-photo sessions. The OCR edit field
  is now height-constrained while remaining editable.
- The new real-world harness initially used brittle filename-visible checks after
  system picker import. It now treats import confirmation as a real UI import
  message or photo-count increase, then uses the existing Reconstruction search
  path with anonymized numeric keys for per-sample processing.
- Formula-region representative flow no longer depends on refinding the filename
  after OCR; it locates the draggable photo region directly.

## Quality Notes

- ML Kit OCR returned terminal success for all five real photos, but recognized
  text was empty for this corpus under current local OCR conditions. This is
  recorded as quality/fixture limitation, not a crash or lifecycle failure.
- No crash/ANR was observed in the accepted real-world run.
