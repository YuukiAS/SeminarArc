# 0.2.x Asset And Processing Job Model Result

## 完成内容

- 新增 `SeminarAssetType` / `SeminarAsset` domain model。
- 新增 `ProcessingJobType` / `ProcessingJobState` / `ProcessingJob` domain model。
- 新增 `SeminarAssetEntity` 与 `ProcessingJobEntity`。
- 新增 `ReconstructionDao` asset/job queries。
- 新增 `ReconstructionRepository` contract 和 `ReconstructionRepositoryImpl`。
- 新增 Hilt binding 与 DAO provider。

## 关键语义

- 每个 asset 必须有 `seminarId`。
- `PHOTO_ENHANCED` 是 derived asset，必须指向 `originAssetId`。
- job 状态持久化为 `QUEUED`、`RUNNING`、`SUCCEEDED`、`FAILED`、`CANCELLED`。
- 同一 input asset + job type 的 active job 幂等复用，不因重复点击无限排队。
