# 0.5.x Formula Provider Contract Task

## Objective

Add the provider-independent formula OCR contract and local-safe manual/unavailable provider implementations without enabling cloud formula OCR or bundling third-party model weights.

## Scope

- Define formula OCR request/result models with seminar/region/source asset identity, normalized crop, rotation, language/context hints, request fingerprint, LaTeX output, confidence, provenance, failure, and retryability.
- Add `FormulaOcrProvider` interface.
- Add `ManualFormulaProvider` for explicit user-supplied LaTeX.
- Add `UnavailableFormulaOcrProvider` as the production default until a live provider is approved.
- Bind the default provider through Hilt.
- Add JVM contract tests with a fake provider plus manual/unavailable provider behavior.
- Update roadmap/privacy/architecture docs and write this result file.

## Out of Scope

- No Mathpix, PaddleOCR, pix2tex, backend, model bundling, account creation, credential storage, external upload, or live network call.
- No formula region UI or durable formula processing Worker implementation.
- No connected Android tests, APK installation, app launch automation, physical-device command, ADB transport reset, or usbipd/WSL manipulation.

## Verification

- Run the targeted JVM provider contract test.
- Run full headless JVM/build checks before commit.
