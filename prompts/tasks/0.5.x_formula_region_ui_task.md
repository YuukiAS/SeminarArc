# 0.5.x Formula Region UI Task

## Objective

Add the first local formula region UI and repository path so users can persist seminar-owned formula regions before any live OCR provider is enabled.

## Scope

- Add `FormulaRepository` and implementation for observing, creating, and deleting formula regions.
- Validate region creation against the seminar-owned source photo asset.
- Show saved formula regions inside Reconstruction workspace photo cards.
- Add a compact local formula-region editor with normalized x/y/width/height fields and a label.
- Add ViewModel actions for create/delete formula region.
- Add Android Compose test compile coverage for formula region controls.
- Update docs/result.

## Out of Scope

- No gesture-based image crop overlay yet.
- No formula OCR job enqueueing, Worker execution, live provider call, external upload, or credential use.
- No Mathpix/PaddleOCR/pix2tex runtime integration.
- No connected Android test execution, APK installation, app launch automation, physical-device command, ADB transport reset, or usbipd/WSL manipulation.

## Verification

- Run headless JVM/build checks and Android test source compile with all Gradle/Android homes on `D:\`.
