# 0.5.x Formula Processing Queue Task

## Objective

Wire saved formula regions into durable local `FORMULA_OCR` processing jobs, using manual LaTeX as the first safe provider path.

## Scope

- Add formula OCR WorkManager payload.
- Add scheduler entry for manual formula OCR.
- Rehydrate formula jobs for retry/recovery from `processing_jobs.inputPayloadJson`.
- Execute manual formula OCR in `ProcessingWorker`.
- Persist formula READY/FAILED results through `FormulaRepository`.
- Add Reconstruction workspace action for queueing manual LaTeX from a saved region.
- Update docs/result.

## Out of Scope

- No Mathpix/PaddleOCR/pix2tex runtime integration.
- No cloud upload, credential storage, backend, model bundling, account creation, production signing, or Google Play action.
- No gesture crop overlay beyond the current normalized region form.
- No connected Android test execution, APK installation, app launch automation, physical-device command, ADB transport reset, or usbipd/WSL manipulation.

## Verification

- Run headless JVM/build checks and Android test source compile with all Gradle/Android homes on `D:\`.
