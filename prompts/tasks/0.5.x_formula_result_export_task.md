# 0.5.x Formula Result Export Task

## Goal

Include ready local formula LaTeX results in SeminarArc's local Markdown and Notion-ready export documents.

## Scope

- Load formula regions and formula results during export assembly.
- Export only READY formula results with non-empty LaTeX.
- Preserve label, source photo path, normalized crop, rotation, provider id/version, confidence, edited flag and provenance.
- Render formula LaTeX as fenced LaTeX in Markdown and as code blocks in Notion-ready preview.

## Out of Scope

- Live Mathpix/PaddleOCR/pix2tex provider calls.
- Cloud upload, credential storage or backend work.
- Exporting failed/queued/cancelled formula states as confirmed formula knowledge.
- Connected device execution against protected physical hardware.

## Validation

- JVM renderer and assembler tests.
- Full unit/compile/lint/internal assemble gate.
- Signature/hash/secret/cache checks before commit.
