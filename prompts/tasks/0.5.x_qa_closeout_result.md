# 0.5.x Automated QA Closeout 结果

## 总结论

`0.5.x automated black-box QA hardening` 已完成。本轮从真实 seminar 私有语料一直推进到 visual、stress 和 API 29/36 matrix，所有最终门禁为绿色。

## 关闭的门槛

- 第二轮真实语料：9 张照片全流程 9/9 PASS；2 段录音完成 private inventory。
- OCR 基本合同：正常可读真实 slide 9/9 产生非空、可用于检索线索的本地 OCR。旧 0/5 是 harness 选择器假阴性，不是 production OCR defect。
- Visual regression：5 个显示 profile、33 个 canonical golden 状态，逐张目检与 comparator PASS。
- Stress：API 36 normal/small 与 API 29 共 3,750 个计入验收的固定 seed 事件，全部无未解释 crash/ANR，恢复 PASS。
- Device matrix：API 36 与 API 29 的 B01/B02/B04/B07 关键路径分别有证据；API 29 task-owned AVD 已关闭，原 API 36 Emulator 保留。
- 总门禁：`compileInternalKotlin testInternalUnitTest lintInternal` PASS；API 36 B07 与 post-fix stress regression PASS。

## 产品修复与 harness 修复

本 Goal 修复了真实但非发布阻断级的产品问题：editor 滚动/错误定位、empty library/filter 可滚动性，以及 OCR 保存提示只在 repository 更新成功后出现。其余主要修复属于 harness：真实语料递归发现、OCR 语义节点定位、system picker 导航、visual baseline/comparator、Android 10 输入映射与外部 Resolver 恢复。

没有发现 P0/P1、系统性 OCR failure、录音数据丢失、持久化破坏或需要用户重新安装验证的 dogfood blocker。

## Release 决策

`NO_NEW_RELEASE`

保持当前可安装版本 `v0.5.0-alpha.2`。本轮价值主要是可靠性证据、测试基础设施和小型 UX 修复；按既定规则不创建无意义的 `0.5.1-alpha.*` tag/Release。
