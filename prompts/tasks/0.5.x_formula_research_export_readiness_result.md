# 0.5.x Formula / Research Export Readiness Result

## Status

`READINESS_PASS`

## Decision

SeminarArc can begin `0.5.x` local-safe production work without a Mathpix account, private API credential, backend, or physical-device automation.

The first production milestone should implement:

- formula region selection data model and local UI state;
- manually editable LaTeX results with confidence/provenance fields;
- provider-independent `FormulaOcrProvider` contract and fake-provider tests;
- deterministic BibTeX/RIS export from confirmed references;
- Markdown/ZIP/Notion-ready export polish for formulas and research references.

## Provider Boundary

- Mathpix is a high-accuracy cloud candidate, but it requires authenticated API access and usage-based billing. Live Mathpix integration is frozen until a later credential/backend/user-key policy is approved.
- PaddleOCR formula recognition is a plausible self-hosted/local research candidate, but model size, runtime, deployment target, and license/dependency audit must be completed before it can ship as a default Android provider.
- pix2tex is useful as an open-source/self-hosted candidate and local development fixture source, but public pretrained weights require a separate license decision before any commercial APK bundling.
- No formula OCR provider should auto-process all seminar photos. Users should select a formula region explicitly before any provider runs.

## Privacy / Scope Boundary

- No external upload was performed.
- No credential, token, paid account, or backend was created.
- No physical-device or connected Emulator command was run.
- `0.5.x` live provider paths remain opt-in and provider-specific; local data model, editing, and deterministic exports can proceed.
