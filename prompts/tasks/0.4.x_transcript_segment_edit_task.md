# 0.4.x Transcript Segment Edit Task

## Objective

Add the first local transcript segment editing loop in Transcript Review without enabling live providers, cloud upload, Notion OAuth/upload, backend deployment, private credentials, or connected device testing.

## Scope

- Add a `TranscriptRepository` API for editing one segment's text.
- Persist edited text through `TranscriptDao` and `TranscriptRepositoryImpl`.
- Mark edited segments with `isEdited = true` and refresh segment/transcript `updatedAt`.
- Keep unsaved segment draft text in `TranscriptReviewViewModel` state.
- Render editable segment fields in `TranscriptReviewScreen` and route saves through the ViewModel.
- Add focused JVM repository tests.

## Out of Scope

- No batch transcript editor.
- No speaker label editing.
- No segment split/merge.
- No live ASR provider.
- No summary provider execution.
- No Notion OAuth/upload.
- No connected Android test or APK installation while Windows ADB can see protected physical device serial `8cc54656`.

## Verification

- Run headless Gradle verification with D-drive local homes:
  - `.\gradlew.bat --no-daemon testDebugUnitTest compileDebugAndroidTestKotlin`
  - `.\gradlew.bat --no-daemon lintDebug assembleInternal`
- Verify the internal APK with `apksigner`.
- Refresh ignored local release staging APK and SHA-256 file.
