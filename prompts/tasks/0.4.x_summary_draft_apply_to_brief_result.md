# 0.4.x Summary Draft Apply To Brief Result

## Status

Implemented.

## Changes

- `TranscriptReviewScreen` now exposes an `Apply to Seminar Brief` action for each summary draft.
- `TranscriptReviewViewModel` maps the selected draft fields into `SaveSeminarBriefInput`.
- Applying a draft calls `ReferenceRepository.saveBrief`, reusing the existing app-owned editable Seminar Brief persistence/export path.
- The action is explicit and local; it does not run in the background and does not call any provider.

## Privacy / Scope Boundary

- Applying a summary draft to `SeminarBrief` is a local Room update triggered by explicit user action.
- No ASR provider, LLM provider, network, Notion OAuth/upload, backend, token storage, private credential, or recurring-cost service is added.
