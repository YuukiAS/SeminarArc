# 0.4.x Transcript Timeline Windows Task

## Objective

Add a provider-independent domain foundation for matching ready transcript segments to seminar timeline events and slide photos.

## Scope

- Build a reusable use case that derives transcript windows around timeline offsets.
- Include `PHOTO`, `MARK`, `QUESTION`, and `NOTE` events by default.
- Match transcript segments by overlap with configurable before/after windows.
- Respect seminar ownership and transcript readiness.
- Prefer photo asset linkage by `sourceTimelineEventId`, with `photoPath` fallback.
- Produce a short preview string for future Reconstruction UI, summary input selection, Markdown-friendly exports, and Notion-prep boundaries.
- Add focused JVM tests.

## Out of Scope

- No schema migration.
- No UI route yet.
- No real ASR provider.
- No summary provider execution.
- No Notion OAuth/upload.
- No connected Android test or APK installation while Windows ADB can see protected physical device serial `8cc54656`.
