# 0.1.2 Full Recording Playback Task

## 目标

完成 seminar 结束后的本地整段 `.m4a` 录音播放闭环，让 `COMPLETED` seminar 的 Detail 页面可以播放真实录音文件。

## 范围

- 使用已有 Media3 dependency，在页面内播放 app-private recording 文件。
- 新增清晰 playback abstraction，生产实现使用 ExoPlayer。
- Detail 页面 recording summary 接入 Play / Pause / Seek、duration、position 和状态文案。
- 播放器只在以下条件同时满足时可用：
  - recording row 存在；
  - `RecordingState == COMPLETED`；
  - `filePath` 非空且合法；
  - app-private 文件实际存在并可读。
- 区分 `FAILED` recording 与 `COMPLETED` 但文件缺失。
- 多 recording row 下采用明确选择规则：选择最新合法 `COMPLETED` recording；最新 `FAILED` 不遮蔽旧的合法 completed recording；不做拼接。
- 页面离开、ViewModel 清理、seminar 删除时释放 player。

## 禁止事项

- 不进入 CameraX、Capture Slide、timeline event、Mark Moment、Quick Note、Question、clip generation、audio stitching、transcription、OCR、AI、waveform、media notification、background playback service 或 `0.1.3`。
- 不修改 Room schema，除非实现中发现不可避免；如修改必须说明 migration。
- 不提交 APK、音频文件、build artifacts、本地配置或凭据。

## 验证

至少运行：

```bash
./gradlew --offline testDebugUnitTest
./gradlew --offline assembleDebug
git diff --check
```

如 lint dependency 已缓存，尝试 `./gradlew --offline lintDebug`；若离线缺缓存则记录原因，不为此篡改依赖配置。
