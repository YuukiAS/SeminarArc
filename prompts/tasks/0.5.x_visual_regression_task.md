# 0.5.x Visual Regression

## 目标

在已经通过的 package-level black-box 用户路径上建立首套 canonical screenshot golden baseline，并以可恢复的 Emulator 显示配置覆盖普通手机、小屏手机、大字体、横屏和 tablet-like profile。识别并修复明显的裁切、遮挡、滚动陷阱、不可达操作、超大卡片和大字体溢出，不把正常的抗锯齿或系统栏像素差异误判为产品缺陷。

## 已授权初始基线

本 task 依据当前 Goal 获得一次创建初始 canonical golden baseline 的明确授权。初始 baseline 只可在逐张检查当前 accepted UI 状态后创建。

baseline 一旦存在：

- 普通测试运行不得覆盖；
- comparison 失败不得自动接受 candidate；
- 后续更新必须使用显式 baseline 接受开关，并形成独立审查证据。

## 允许动作

- 修改现有 black-box harness，按显式开关在稳定状态采集额外 screenshot/UI tree。
- 新增 visual regression runner、图片比较工具、baseline manifest 和小型 synthetic golden PNG。
- 对 `emulator-5554` 显式设置并恢复 `wm size`、`wm density`、`font_scale` 和 rotation，用于限定的显示 profile。
- 只使用 synthetic/deterministic App 数据；不得把真实 seminar 截图纳入 tracked golden。
- 发现普通 Compose 布局、滚动、语义或可达性问题时，直接修复 production code、补测试并复测。
- 运行必要的 Gradle/JVM/lint/Emulator 回归，写 result/review 并提交普通 commit。

## 禁止动作

- 不触碰 GM1910 / `8cc54656`，不运行 unscoped connected/device task。
- 不执行 `adb kill-server`、transport reset、usbipd、WSL shutdown 或真机恢复。
- 不提交 private real-world screenshot、OCR 全文、录音内容或文件映射。
- 不因 comparison 失败自动覆盖已有 baseline。
- 不创建 tag、Release、production signing、Google Play 或外部上传。

## 覆盖范围

稳定状态至少覆盖：

- empty library、populated library、New Seminar、Seminar Detail；
- Active Session；
- Reconstruction、Reference Review、Transcript Review；
- Formula UI；
- export/document picker 主状态；
- error/deferred-provider、empty 和 processing 状态。

显示 profile 至少覆盖：

- normal phone：1080x2400、density 420、font scale 1.0；
- smaller phone；
- enlarged font scale 1.3；
- landscape；
- tablet-like width。

## 验收门槛

1. 每个 golden 都来自本 task 当前运行，且在接受前已实际打开检查。
2. baseline manifest 记录 profile、scenario、viewport 和稳定状态标签，不记录私有内容。
3. compare 模式在 baseline 缺失、尺寸不符或显著视觉差异时失败，并保留 candidate/diff 私有证据。
4. 正常 run 不得修改 baseline；只有显式初始/更新开关可以写入。
5. 配置修改在 `finally` 中恢复到运行前的 size、density、font scale 和 rotation。
6. 所有 ADB 写操作显式限定到 `emulator-5554`。
7. `git diff --check` 与相关验证通过；task-owned 文件不包含 `Microsoft/` 或任何 private 数据。
