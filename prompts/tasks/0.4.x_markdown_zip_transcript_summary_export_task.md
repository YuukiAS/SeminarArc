# 0.4.x Markdown/ZIP Transcript Summary Export Task

## Objective

Extend SeminarArc local Markdown/ZIP export so `0.4.x` transcript review data, transcript timeline windows, and generated summary drafts are preserved in user-controlled export artifacts.

## Scope

- Include local transcript metadata, state, source, timestamped segments, edit/confidence annotations, and provider identity in Markdown export.
- Include locally derived transcript timeline windows for ready transcripts.
- Include generated summary drafts as explicitly editable generated drafts.
- Preserve the boundary that generated drafts do not overwrite the user-authored `SeminarBrief`.
- Keep ZIP structure compatible by continuing to write `<seminar-slug>/seminar.md` plus readable media assets.
- Add focused JVM tests for export assembly and Markdown rendering.

## Out of Scope

- No live ASR provider.
- No live LLM summary provider.
- No Notion OAuth/upload.
- No backend, private credential, cloud upload, or recurring-cost service.
- No connected Android test or APK installation while Windows ADB can see protected physical device serial `8cc54656`.
