# 0.5.x Formula Region Edit Selection Task

## Goal

Allow users to revise a saved formula region's label and normalized crop by loading it into the existing draft controls and explicitly updating it.

## Scope

- Add a repository update path for existing formula regions.
- Preserve existing seminar ownership, source asset id and source photo path during updates.
- Add Reconstruction workspace UI controls to load a saved region into the draft fields.
- Require an explicit update action before persisting changes.
- Keep existing formula results attached to the same region id.
- Add Compose coverage for edit/update actions.

## Out of Scope

- Drag resize handles on persisted rectangles.
- Automatic provider rerun after crop update.
- Live formula OCR provider execution.
- Cloud upload, credential storage, backend, Zotero sync or Notion live upload.
- Connected device execution against protected physical hardware.

## Validation

- JVM tests and androidTest Kotlin compile.
- Lint and internal APK build.
- Signature/hash/secret/cache checks before commit.
