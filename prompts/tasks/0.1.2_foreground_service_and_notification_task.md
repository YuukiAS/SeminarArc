# 0.1.2 Foreground Service、Notification 与真实本地录音

## 目标

实现 `0.1.2` 第二阶段：真实 microphone foreground recording service、本地 seminar-owned recording file、`RecordingEntity` durable lifecycle、ongoing notification，以及下一阶段 Active Session UI 可调用的最小应用层入口。

## 范围

- 按当前 Android Developers 官方文档核对 targetSdk 36 下 microphone foreground service、`RECORD_AUDIO`、`FOREGROUND_SERVICE_MICROPHONE` 和 `POST_NOTIFICATIONS` 行为。
- 增加 manifest permissions 与 `android:foregroundServiceType="microphone"` service declaration。
- 实现 production `RecorderController` backend，使用 Android 本地录音 API 生成 app-private seminar-owned audio file。
- 建立 `RecordingRepository`，集中维护 `RecordingEntity` 的 `RECORDING`、`COMPLETED`、`FAILED` 状态。
- 增加 foreground service、notification channel 和 ongoing notification。
- 提供最小 use case / starter，让 UI 按 `startSeminarSession(seminarId)` 结果和麦克风权限启动 service。
- 补充 unit tests，用 fake controller/backend 覆盖硬件无关 orchestration。
- 更新 `docs/PRIVACY.md` 和 `CHANGELOG.md`。

## 明确不做

- 不实现 CameraX。
- 不实现 timeline photo/note/question/mark 正式功能。
- 不实现 clip generation、WorkManager clip processing 或 Media3 playback UI。
- 不实现完整 Live Capture 页面。
- 不加入 OCR、transcription、AI summary、Notion、cloud provider、ads 或 payment。
- 不做大规模 UI redesign。

## 验收条件

- `RECORD_AUDIO` denial 不启动真实 recorder，不创建 `RECORDING` row。
- `POST_NOTIFICATIONS` denial 不被建模为 recorder hard failure。
- service duplicate `START` 不创建第二个 recorder 或第二个 recording row。
- 正常 start 创建 seminar-owned file 和 `RecordingEntity(RECORDING)`。
- 正常 stop finalize 文件并写 `COMPLETED` 和 duration。
- start/stop/finalize failure 写 `FAILED`，不伪装 completed。
- notification channel 创建幂等，ongoing notification 可返回 app。
- Room schema 不变，除非现有 schema 无法表达本阶段事实。
- 运行：
  - `./gradlew --offline testDebugUnitTest`
  - `./gradlew --offline assembleDebug`
