# Review — 0.5.x Black-box Research Flows

Status: `OPEN_NEXT_TASK`

## 结论

本轮达到预期的 research-flow black-box 验收边界，并暴露出一个清晰、窄范围的剩余 blocker：**稳定 photo fixture**。

- B01/B02/B03/B08 regression：PASS。
- B05 Reference workflow：provider 可用时 PASS；provider timeout/error 正确归类为 `BLOCKED_BY_EXTERNAL_PROVIDER`，不属于 production regression。
- B06 Transcript / Summary local-safe：PASS。
- B04 Reconstruction：受 Emulator CameraX fixture 不稳定阻塞。
- B07 Formula photo path：继承 B04 的 saved-photo blocker；独立 export surface 已得到实际文件验证。
- unit/build/lint/24-test Emulator regression：PASS。
- GM1910：未作为目标。

## 证据判断

当前证据足以确认 harness 本身已经覆盖并验证了基础 CRUD/session/recovery、reference/manual evidence、manual transcript、DocumentsUI export 等真实用户流，并抓到/修复了两个真实 production 问题：

1. CameraX capture stall 现在有 15s bounded timeout，不再无限挂起 UI；
2. `Find references` 不再错误依赖 OCR/key-slide，manual DOI/title workflow 可达。

B04/B07 不应因为缺照片 fixture 被直接判为产品失败；它们的阻塞点是测试环境可重复性，而不是已证实的 production defect。

## 下一步判断

**不建议立刻进入 visual regression。**

先建立 deterministic Emulator photo fixture 并只针对 B04/B07 做 focused closeout，更有价值：

- Android Emulator 官方支持 image-backed camera source；
- 一旦 saved photo 可稳定产生，B04 Reconstruction 与 B07 formula crop/manual LaTeX 可以真正闭环；
- visual golden 应尽量建立在主要 screen state 已可稳定到达之后，避免给“不完整路径”做 baseline。

同时，本轮运行耗时过长，下一任务必须支持按 scenario 精确运行，避免每次都重新跑 66-step 全量 harness。

## Provider 边界

OpenAI API、Mathpix、真实 ASR/LLM/Formula OCR、Notion OAuth/backend 暂不作为当前 QA blocker。

用户计划在 2026-10 再决定短期付费 provider 与后续 Mac mini 本地开源模型路线。在此之前继续验证 provider contract / unavailable UI，不提前实现真实 paid provider。

## Release 决策

当前仍不建议仅为本轮修复发布 `0.5.1-alpha`。

优先完成 deterministic photo fixture closeout；随后结合 B04/B07、real-world media corpus 和 visual regression 再统一判断是否值得发新的 internal alpha。
