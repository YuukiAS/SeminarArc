## Product assessment

这次不仅是 QA workaround，而是补上了合理产品能力：seminar 后从系统相册/文件补入已有 slide/photo。该能力与现场 CameraX capture 并存，不应绑定伪造 timeline offset。

当前主要 automated workflow 状态已经从“基础流程未闭环”推进到“synthetic deterministic flow 已闭环，下一步验证真实 seminar 媒体 robustness”。因此不建议继续投入第三种 Emulator camera hack。

## Remaining risks

下一阶段关注真实数据分布，而不是继续证明按钮可点击：

- 真实投影照片的 skew / glare / moire / blur / small text / color cast；
- 中英混合 OCR 在真实 seminar 条件下是否稳定完成并产生可用 clue；
- 真实公式/图表页导入后，formula region 与 enhancement 是否仍可操作；
- 真实 PDF abstract/import 生命周期；
- 处理 latency / failure / memory 是否出现明显退化。

真实 CameraX 拍摄质量、方向、长时录音、锁屏/后台和厂商 ROM 行为仍属于后续真实硬件 acceptance，不应由 real-world imported-photo corpus 代替。

## Privacy boundary for next task
