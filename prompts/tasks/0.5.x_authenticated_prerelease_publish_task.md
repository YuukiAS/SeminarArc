## Publish

先运行：

```powershell
gh release view v0.5.0-alpha.2 --repo YuukiAS/SeminarArc
```

若不存在，使用已有 tag 创建 prerelease：

```powershell
gh release create v0.5.0-alpha.2 `
  release/SeminarArc-0.5.0-alpha.2.apk `
  release/SeminarArc-0.5.0-alpha.2.apk.sha256 `
  --repo YuukiAS/SeminarArc `
  --title "SeminarArc v0.5.0-alpha.2" `
  --notes-file docs/releases/v0.5.0-alpha.2.md `
  --prerelease `
  --verify-tag
```

若 release 已部分存在，只补缺少 asset；不要重复创建对象。若同名 asset 已存在，先核对 hash，再决定是否需要安全替换。
