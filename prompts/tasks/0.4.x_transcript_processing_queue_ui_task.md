# 0.4.x Transcript Processing Queue UI Task

## Objective

Expose local `TRANSCRIPTION` and `SUMMARY_DRAFT` durable job status in Transcript Review and add retry/cancel controls without enabling live providers, cloud upload, Notion OAuth/upload, or connected device testing.

## Scope

- Observe seminar processing jobs in `TranscriptReviewViewModel`.
- Filter the Transcript Review queue surface to transcript-related job types.
- Render persisted job state, provider identity, and error messages in `TranscriptReviewScreen`.
- Route retry and cancel actions through `ProcessingWorkScheduler`.

## Out of Scope

- No live ASR provider.
- No live summary provider.
- No Notion OAuth/upload.
- No backend or token storage.
- No connected Android test or APK installation while Windows ADB can see protected physical device serial `8cc54656`.

## Verification

- Run headless Gradle verification with D-drive local homes:
  - `.\gradlew.bat --no-daemon testDebugUnitTest compileDebugAndroidTestKotlin`
  - `.\gradlew.bat --no-daemon lintDebug assembleInternal`
- Verify the internal APK with `apksigner`.
- Refresh ignored local release staging APK and SHA-256 file.
