## Goal

Implement the local-safe persistence and use-case layer that can run a fake/local `TranscriptionProvider` against an app-owned completed recording and save timestamped transcript segments.

## Required Work

- Add Room DAO coverage for transcript rows, segments, and summary drafts.
- Add `TranscriptRepository` and `TranscriptRepositoryImpl`.
- Add a use case for running transcription from a completed recording through a `TranscriptionProvider`.
- Use `RecordingRepository`, `ReconstructionRepository`, and `MediaStorageManager` boundaries instead of direct Room/file access from domain use cases.
- Save transcript lifecycle as `QUEUED -> RUNNING -> READY/FAILED`.
- Save timestamped segments with seminar and recording ownership.
- Reuse existing ready transcript for the same recording/provider where safe.
- Add JVM tests with fakes only; no live transcription provider or credentials.

- No cloud upload, Notion OAuth, backend deployment, private API credential, production signing, Google Play, ads, or payments.
- Do not run connected Android tests while Windows ADB sees protected physical device serial `8cc54656`.
- Do not claim real transcription quality; fake-provider tests only prove the contract and persistence flow.
