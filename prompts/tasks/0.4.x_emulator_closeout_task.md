# 0.4.x Emulator Closeout Task

## Objective

Attempt the `0.4.x` local closeout gate for the current `origin/main` head, while preserving the Windows Emulator-first and protected physical-device safety policy.

## Scope

- Confirm the working tree is clean after local-safe `0.4.x` implementation work.
- Reuse the most recent headless Gradle verification evidence:
  - `testDebugUnitTest`
  - `compileDebugAndroidTestKotlin`
  - `lintDebug`
  - `assembleInternal`
  - `apksigner verify`
  - local staging APK SHA-256
- Run only the allowed read-only Windows ADB preflight: `D:\Android\Sdk\platform-tools\adb.exe devices -l`.
- Stop connected testing if the preflight cannot prove that only `emulator-*` devices are visible.

## Out of Scope

- No APK installation.
- No connected Android tests.
- No app launch automation.
- No `adb kill-server`, transport reset, reconnect, usbipd attach/detach/bind/unbind, physical-device command, or WSL restart.
- No version tag, GitHub Actions dispatch, or GitHub Release unless the full local connected Emulator gate passes.

## Verification

- Record the preflight result and explain whether the connected gate can proceed.
