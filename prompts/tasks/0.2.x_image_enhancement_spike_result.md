# 0.2.x Image Enhancement Spike Result

## 官方来源

- Android `Bitmap`: https://developer.android.com/reference/android/graphics/Bitmap
- Android `Matrix`: https://developer.android.com/reference/android/graphics/Matrix
- Android `ColorMatrixColorFilter`: https://developer.android.com/reference/android/graphics/ColorMatrixColorFilter
- OpenCV Android usage models: https://opencv.org/opencv4android-usage-models/
- OpenCV license: https://opencv.org/license/
- OpenCV Android tutorial: https://docs.opencv.org/5.0/tutorials/introduction/android_binary_package/dev_with_OCV_on_Android.html

## 结论

`0.2.x` 第一版先采用 Android 原生 Bitmap/Canvas/Matrix/ColorMatrix 管线，不引入 OpenCV 依赖。

理由：

- 需求仅为 rotate、crop、manual perspective correction、basic contrast/readability、thumbnail。
- Android `Bitmap.createBitmap` 支持裁切和 Matrix 变换；`Matrix.setPolyToPoly` 可表示四点透视映射；`ColorMatrixColorFilter` 可覆盖基础对比度/饱和度/亮度处理。
- 不引入 OpenCV 可降低 APK 体积、native ABI 风险和 build 复杂度。
- OpenCV 4.5+ license 为 Apache 2.0，且 Android AAR 从 4.9.0 起可通过 Maven Central 使用；若后续需要自动边缘检测、文档扫描、去眩光或更复杂形态学处理，可再引入 OpenCV。

## Pipeline 决策

- 原图永远保留为 `PHOTO_ORIGINAL` asset。
- 增强输出为 `PHOTO_ENHANCED` derived asset，`originAssetId` 指向原图。
- 输出路径放在 seminar-owned app-private `enhanced/` 或 `photos/enhanced/` 子目录。
- 失败或取消不得删除原图；只更新 `processing_jobs`。
- thumbnail 使用派生/原图读取时按目标尺寸 decode，避免全尺寸缩略图列表 OOM。

## 第一版能力

- rotate: 90/180/270 degrees。
- crop: bounded rectangle。
- perspective: 用户给定四角点，生成矩形目标 bitmap。
- readability: brightness/contrast/saturation preset，保留可撤销的参数记录。

## 后续可选 OpenCV trigger

只有当需要自动 slide boundary detection、adaptive threshold、dewarp 或更强去噪时再引入 `org.opencv:opencv`，并单独评估 APK size、ABI、license notice 和 ProGuard/R8。
