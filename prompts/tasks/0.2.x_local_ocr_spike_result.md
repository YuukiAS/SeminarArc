# 0.2.x Local OCR Spike Result

## 官方来源

- ML Kit Text Recognition v2 Android: https://developers.google.cn/ml-kit/vision/text-recognition/v2/android?hl=en
- ML Kit model installation paths: https://developers.google.com/ml-kit/tips/installation-paths?hl=en
- ML Kit release notes: https://developers.google.com/ml-kit/release-notes
- ML Kit Terms & Privacy: https://developers.google.com/ml-kit/terms
- ML Kit Android data disclosure: https://developers.google.com/ml-kit/android-data-disclosure

## 结论

`0.2.x` 第一版选择 ML Kit Text Recognition v2 **bundled** artifacts：

- `com.google.mlkit:text-recognition:16.0.1`
- `com.google.mlkit:text-recognition-chinese:16.0.1`

原因：

- 项目 `minSdk = 26`，满足当前 ML Kit Text Recognition v2 Android API 23+ 要求。
- bundled model 随 app 安装，首次无网络也可用；unbundled 依赖 Google Play Services 动态下载，首次离线可能失败。
- Latin + Chinese 覆盖本阶段 English / Chinese / mixed slide OCR；mixed 图片可先运行 Latin 与 Chinese recognizer 并合并去重，后续根据实测优化。
- 不需要 API key，不上传 seminar photo。

## Offline 行为

- 核心 OCR 路径必须在安装后无网络可运行。
- 不使用 `play-services-mlkit-text-recognition*` 作为第一版默认依赖，因为其模型需要 Google Play Services 管理/下载。
- 应在 Emulator smoke 中验证 airplane/offline 状态下已安装 app 的 OCR 可执行；不把首次动态下载成功作为 local-first 依据。

## 隐私与数据披露

- ML Kit 文档说明输入数据和输出在设备端处理，不发送给 Google servers。
- 仍需在隐私文档中披露 ML Kit SDK 可能收集 diagnostics / usage metrics、device/app info、performance metrics、API configuration、feature input/output size、error/event data。
- OCR 文本是用户 seminar 内容，应保存在 app-owned Room，不写入 crash/logcat/analytics。

## Implementation notes

- `TextOcrProvider` 暴露 app-owned `OcrRecognitionResult`，不泄漏 ML Kit private response。
- Provider 只接收 app-private `SeminarAsset` 或 resolved local file，不由 Compose 直接调用。
- ML Kit `Task` 需要桥接到 coroutine cancellation；取消 app job 后不得写入 stale success result。
- 对低文本/空图片返回成功空结果，而不是异常。
