# 0.4.x Summary Draft Apply To Brief Task

## Objective

Connect local summary drafts to the existing editable Seminar Brief workflow through an explicit user action.

## Scope

- Add a Transcript Review action for applying one summary draft to `SeminarBrief`.
- Copy the selected draft fields through `ReferenceRepository.saveBrief`.
- Keep the action local, explicit, and compatible with existing Reference Review, Markdown/ZIP export, and Notion-ready export contract paths.

## Out of Scope

- No automatic background overwrite of `SeminarBrief`.
- No live LLM provider.
- No Notion OAuth/upload.
- No backend, token storage, private credential, or recurring-cost service.
- No connected Android test or APK installation while Windows ADB can see protected physical device serial `8cc54656`.

## Verification

- Run headless Gradle verification with D-drive local homes:
  - `.\gradlew.bat --no-daemon testDebugUnitTest compileDebugAndroidTestKotlin`
  - `.\gradlew.bat --no-daemon lintDebug assembleInternal`
- Verify the internal APK with `apksigner`.
